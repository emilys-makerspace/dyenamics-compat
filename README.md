# Dyenamics Compat

Extra Dyenamics colors for other Minecraft mods, with no hard mod dependencies or color mixins. Content is registered only when its compatible mods are installed.

**Minecraft 1.21.1 · NeoForge 21.1.252 · Java 21**

Adds 18 extra colors to **Create**, **Supplementaries**, **Supplementaries Squared**, **Quark**, and dyeable families in **[Let’s Do] Brewery, Camping, Furniture, Hearth & Timber, and Lili’s Pottery**. Find variants beside their originals in existing creative tabs.

See the [roadmap](ROADMAP.md) for planned compatibility.

## Development

With JDK 21:

```sh
./gradlew build
./gradlew runClient
```

Development dependencies are downloaded automatically from the pack’s pinned versions.
